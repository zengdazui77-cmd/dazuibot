# 数据与隐私

简体中文 | [English](./privacy_en.md)

**一句话结论：** 对话、记忆、文件和密钥存在你的设备上；发给模型的内容会经过本站的中转服务转给你选定的模型供应商。我们不声称能做到万无一失——凡是发给模型的内容，都会离开你的设备。

这份文档说明 dazuibot 把什么存在哪里、什么会离开你的设备、怎么删除。有问题请通过你获取本软件的渠道联系我们。

## 数据目录

| 运行方式 | 数据目录 |
| :--- | :--- |
| 桌面版 · Windows | `%APPDATA%\zdzui-assistant\data` |
| 桌面版 · macOS | `~/Library/Application Support/zdzui-assistant/data` |
| 桌面版 · Linux | `~/.config/zdzui-assistant/data` |
| 命令行 `npm start` | `./data`（固定，不读环境变量） |
| Docker | 容器内 `/data`（README 示例里挂载为卷 `amb-data`） |

| 数据 | 存放位置（数据目录内） | 会离开设备吗 | 去向 |

## 账户与登录

- 本分发**不提供账户登录**：不需要注册，应用也不会向站点索取你的账号密码，数据目录里不会留下登录凭据。
- API Key 只存在本机（内置网关的隔离配置 `magpie/config/`），随每次模型请求作为鉴权发出；应用不把它写进日志，界面只显示尾号。
- 怀疑 Key 泄漏：到站点的控制台把这一把 Key 删掉、重新签发，再在应用里换上新的一把。

## 本地控制台的访问控制

- 管理界面默认只监听 `127.0.0.1:3600`，局域网和公网访问不到。
- 桌面版每次启动都会生成一个随机访问令牌，其他本机程序无法直接调用管理接口。
- 监听非回环地址时（例如 Docker 里的 `0.0.0.0`）强制令牌访问，令牌在数据目录的 `ui-token`（Docker：`docker exec amb cat /data/ui-token`）。
- 不要把 3600 端口直接暴露到公网；需要远程访问时，请放在你自己控制的 VPN 或带鉴权的反向代理后面。

## 模型请求

- 模型请求由内置的 magpie 网关发往本站的中转服务（地址编译在客户端里，不能改），再由它转给你选定的模型供应商。
- 请求里包含模型回答所需的内容：提示词、对话上下文、被用到的记忆、文件内容、工具结果，以及电脑操作时的截图。
- 请求带有 `X-Modelflare-Skill: zdzui-assistant/<版本>` 头，用于在服务端标识来源（头名是协议标识，不能改；值是本产品）；应用里打开的站点链接带 `utm_source=zdzui`。
- 中转服务会保留请求日志；保留什么、保留多久，由本站服务提供方决定，请向其咨询。各模型供应商对数据的处理，以它们各自的条款为准。

## 遥测

- 内置电脑操作驱动（Cua Driver）的遥测通过环境变量 `CUA_TELEMETRY_ENABLED=0`、`CUA_DRIVER_RS_TELEMETRY_ENABLED=0` 关闭。
- 内置网关 magpie 以关闭自动更新、关闭账户发现的方式运行，不读取你电脑上已有的其他 AI 工具凭据。
- 本产品自有代码（`src`、`electron`、`ui`、`scripts`、`dsh-runtime/plugins`）里没有分析或遥测上报：搜索 telemetry、analytics、sentry、posthog、mixpanel，只命中上面 Cua 的两个环境变量。
- 随附的第三方组件各自的行为以它们的文档为准，这里不作保证。

## 应用自己会发起的其他网络请求

除模型请求外，应用还会在以下情况联网：

- 读取本站中转服务的模型目录、余额、用量和通知（你的账户数据）。
- 生成图片或视频时，从站点的模型文档接口读取该模型的请求格式。
- 微信渠道：与 `ilinkai.weixin.qq.com` 通信，并从微信 CDN 下载你发来的图片和文件。
- 飞书渠道：与飞书开放平台保持长连接。
- Telegram、Slack、Discord 渠道：接入后与 `api.telegram.org`、`slack.com`、`discord.com` 及其文件地址通信，用来收发消息和你发来的文件。
- Windows 上开启代理模式且系统里没有可用的 PowerShell 7 时，从微软官方发布地址下载 PowerShell 7（可用 `config.json` 的 `agent.pwshAutoInstall: false` 关闭，详见[开发文档](./development.md)）。

## 电脑操作与截图

- 读取屏幕会截图，截图作为模型请求的一部分发给支持视觉的模型。
- **电脑操作默认关闭**，需要你在 机器人设置 → 电脑操作 里主动开启，首次开启时会说明数据范围。
- 开启后默认「改变界面的操作先问我」；读取屏幕仍然自动。可以改成「所有操作自动执行」，但读取屏幕与操作的行为都会直接发生。
- 权限预设为「只读」的机器人只开放读取类工具。

## 渠道

- 你在微信、飞书、Telegram、Slack、Discord 里和机器人收发的消息，会经过这些平台的服务器，受它们各自的隐私政策约束。
- 默认只有主人和你允许的人能和机器人对话；其他人发来的消息不会交给模型，只登记成使用请求（见 [开发文档](./development.md#谁能使用机器人)）。

## 如何删除数据

1. 退出 dazuibot（托盘菜单 → 退出）。
2. 删除上面表格里的数据目录。Docker：`docker rm -f amb && docker volume rm amb-data`。
3. 如果你在站点生成过 API Key，到站点控制台把它删掉（它只存在你的设备上，删掉数据目录也会一并消失）。
4. 如有需要，在飞书开放平台停用你创建的应用（包括扫码时自动创建的），在微信里解除与机器人的绑定；在 Telegram（@BotFather）、Slack、Discord 上删除你创建的机器人；在 Notion 的设置里断开本应用的连接，删除你创建的令牌。
